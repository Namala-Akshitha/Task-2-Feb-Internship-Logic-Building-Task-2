# Data Science Internship – February 2026
## Task 2: Python Logic Building

### Overview
This repository contains my solutions for Task 2 of the Data Science Internship – February 2026. The assignment focuses on Python programming fundamentals and basic data manipulation using lists, sets, dictionaries, loops, and strings.

### Problems Solved

1. **Unique Words in a Sentence** – Identify unique words and count them using sets.
2. **Highest Salary from Employee Data** – Find the employee with the highest salary using a dictionary.
3. **Find Maximum and Minimum Values** – Identify the largest and smallest numbers in a list.
4. **Count Products Above a Price Threshold** – Count products priced above 1000.
5. **Calculate Attendance Percentage** – Calculate attendance based on present and absent records.
6. **Remove Duplicate Phone Numbers** – Remove repeated phone numbers using sets.
7. **Count Character Frequency** – Count the occurrences of each character in a string using a dictionary.
8. **Convert List to Tuple** – Convert a list into a tuple.
9. **Check if a Key Exists in a Dictionary** – Verify whether a specified key is present in a dictionary.
10. **Calculate Average Marks** – Calculate the average of a list of student marks.
